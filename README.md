# Emdee releases

Distribution channel for [Emdee](https://github.com/aaronjellis/Emdee), a
fast, native markdown viewer and editor for macOS.

This repository contains **only build artifacts**:

- `appcast.xml` — the Sparkle update feed, served via GitHub Pages
- Notarized `.dmg` builds, attached to each GitHub Release

Application source lives in a separate repository. Nothing is published
here until a build has been signed, notarized, stapled, and explicitly
released.

## Installing

Download the latest `.dmg` from
[Releases](https://github.com/aaronjellis/emdee-releases/releases),
open it, and drag Emdee to your Applications folder.

Emdee checks for updates automatically. You can also check manually from
**Emdee → Check for Updates…**
